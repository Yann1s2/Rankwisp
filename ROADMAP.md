# Rankwisp roadmap

This is a public preview. The items below are priorities, not release-date promises.
[Try the demo](https://rank.zhstudio.ch/app/?demo=1) · [Contribute](CONTRIBUTING.md)

## Available now

- [x] Keyword research across 20 Apple storefronts, observed positions and inspectable history.
- [x] Competitor comparison, archives, import/export and recovery safeguards.
- [x] English/German UI, responsive layouts and keyboard support.
- [x] Editable AI keyword proposal flow, with explicit consent and manual fallback.
- [x] Cloudflare backend, local Node alternative and MIT source.
- [x] Browser demo and macOS/Windows/iOS Simulator preview artifacts.

## Before a general release

- [ ] Configure Google OAuth and verify real web/native sign-in, cancellation and persistence.
- [ ] Configure an AI provider and verify live Luna availability, output and actual cost.
- [ ] Test the Windows package on Windows and iOS on a physical device.
- [ ] Complete Developer-ID signing/notarization and other distribution signing.
- [ ] Validate infrastructure backup recovery and durable backend CI credentials.
- [ ] Complete operator, legal and merchant setup before enabling purchases.

## Useful first contributions

- **First-run feedback:** follow the quick start on a clean machine and report the exact step that is unclear.
- **Language review:** improve one English/German screen with a concrete before/after example.
- **Accessibility:** check a single flow using VoiceOver or keyboard-only navigation and include reproduction steps.
- **Windows verification:** report OS version, startup result and an anonymized screenshot of the preview.
- **Storefront examples:** document a reproducible public Apple API observation, keeping API order distinct from iPhone search.

Keep changes focused. Open a feature request before starting a large implementation so scope can be discussed. Never include user data, private exports, API keys or unlabelled invented measurements.
